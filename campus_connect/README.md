# 🎓 Campus Connect

Campus Connect is a responsive web application built using HTML, CSS, and JavaScript to help students stay connected with campus activities.

## 🚀 Features

- 🏠 Responsive Homepage
- 📅 Events Section
- 📢 Announcements
- 👥 Clubs
- 🔍 Search Functionality
- 📱 Mobile Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
campus_connect/
│── index.html
│── style.css
│── script.js
│── README.md
```

## 💻 Run Locally

1. Clone the repository

```
git clone https://github.com/Jasvitha27/campus-connect.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
